# Safety

Read before any procedure. Helpers need this too.

Jump: [System Design](#system-design) · [User’s guide](#users-guide) · [Builder’s guide](#builders-guide) · [Hazards](#hazard-register) · [The numbers](#the-numbers-that-matter)

::: {.danger}
Carbon monoxide. Exhaust ends in open air, away from intake and cabin openings. Stop if exhaust can reach breathing air. Never run the Hydronic D5S diesel heater in a closed garage. → [HAZ-002](#haz-002)
:::

::: {.danger}
Fire and fuel. Fuel line off the exhaust. Engine and heater off during fuel work. Inspect before first fire. Do not light to “test” a wet line. Diesel EN 590; ≤20% FAME OK; pure biodiesel not ([SRC-009](#src-009)). → [HAZ-001](#haz-001) · [HAZ-008](#haz-008)
:::

::: {.danger}
Scalding. Tap water can track glycol (~150–185°F). Use only the AM100-1LF thermostatic mixing valve on the Duda B3-12DW-20 plate heat exchanger (~120°F, labeled). Mixed outlet only ([DEC-008](#dec-008)). → [HAZ-005](#haz-005)
:::

::: {.danger}
Shock / fire — Isotemp element. 750 W / 115 VAC on Paneltronics **WATER HEATER** only — never 12 V ([DEC-004](#dec-004) / [DEC-020](#dec-020)). Never on an empty chamber. Upstream GFCI/ELCI + route before first use ([HOLD 9](#hold-9)). → [HAZ-006](#haz-006) · [HAZ-009](#haz-009)
:::

::: {.caution}
Hot glycol / steam. Loop full and bled; heater ≤2.5 bar; WFT cap ~1.2 bar; never run the pump dry; check WFT only when cool; treat running hoses as burn-hot. Lukewarm cabin heater with burner on usually means air or a kink (min flow ~250 l/h). → [HAZ-003](#haz-003)
:::

::: {.caution}
Air lock / overheat / lockout. Reinforced hose, no forced kinks, bleeders at high points. ≤2 EasyStart Timer off/on into a fault; clear locks with diagnostics ([SRC-009](#src-009)). After overheat, wait until coolant is below ~70°C. Work on exhaust only when cold. → [HAZ-010](#haz-010)
:::

::: {.must}
Glycol and drinking water stay apart (Duda double wall only — [DEC-003](#dec-003)). Cap unused ports. Mix ≤50% propylene glycol, one brand. Heater supply about 10.5–16 V. No overnight heat above ~5,000 ft without Altitude kit 22 1000 33 22 00 ([DEC-006](#dec-006)). → [HAZ-007](#haz-007) · [HAZ-011](#haz-011)
:::
