# How to Use This Book

Read in this order: [Safety](#safety) → [System Design](#system-design) → [The Numbers](#the-numbers-that-matter) → [User’s Guide](#users-guide) → [Current Status](#current-status-report) → [Builder’s Guide](#builders-guide).

| Stage | Chapter |
|---|---|
| Architecture | [System Design](#system-design) |
| Day-to-day (after Acceptance) | [User’s Guide](#users-guide) |
| Install | [Builder’s Guide](#builders-guide) |

Skim [The Numbers](#the-numbers-that-matter) as a card. While you build, return to Safety, [Controls](#controls), and [The Parts](#the-parts) when a HOLD points there. Do not light the heater from the User’s Guide until [Acceptance](#acceptance).

**Two finish lines.** Diesel cabin heat / diesel hot water can pass before [HOLD 9](#hold-9). Complete system (Isotemp AC) needs HOLD 9. Install map: top of the [Builder’s Guide](#builders-guide).

**Lookups.** [The Numbers](#the-numbers-that-matter) · [Isotemp value study](#isotemp-value-study) · [Sources](#source-register) · [Decisions](#decision-log) · [Questions for You](#questions-for-you-in-order) · [Open Questions](#open-questions) · [Hazards](#hazard-register) · [Locked facts checklist](#locked-facts-checklist). Part names: [The Parts](#the-parts). On van vs garage: [Current Status](#current-status-report). Part two is reference, not the work order. DANGER / CAUTION / MUST boxes win.
